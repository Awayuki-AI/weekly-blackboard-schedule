ADS 2ヶ月目課題 · 図解

面倒な報告を自動化する
黒板予定ツールの流れ

毎週、年間予定から子ども向けだけを抜き出し、月曜に黒板へ書く表を渡していた作業を、 日曜夜の自動更新とメール通知に置き換えた。

01 何が変わったか

以前（手作業）

  • 校務の年間予定を目で追う
  • 子どもに関係する行をピックアップ
  • 表を作って月曜に渡す

いま（自動化）

  • 年間Excelを取り込む
  • 日曜20時に今週分HTMLが更新
  • GmailにURLが届き、印刷するだけ
02 自動化ツールの4パーツ
TRIGGER

トリガー

毎週日曜 20:00
GitHub Actions。朝6時出勤前に表ができている。

SOURCE

ソース元

学校の年間予定Excel
閲覧のみ原本はダウンロード。行事予定列だけ使う。

PROCESS

処理

翌月曜〜日曜を抽出
全月シートから該当週だけ抜き、印刷用HTMLにする。

DELIVER

届ける先

Pages ＋ メール
同じURLを更新し、Gmailへ「今週分のリンク」を送る。

03 データの流れ
学校Excel（年間） → 行事予定だけ抽出 → school-events.json → 印刷用HTML → GitHub Pages → Resend → Gmail
04 つくるときに決めたこと

校務サイト直結は諦めて、ダウンロード運用にした

掲示板はログイン必須で自動取得できなかった。 CSVは月ごと、Excelなら年間一括——なのでExcelを正とした。 日直名などが入る原本は公開せず、行事だけをjsonにして自動更新に乗せる。 2学期に学校Gmailが使えるようになったら、メール宛先だけ差し替える。
