教室の黒板予定を、
日曜のメール1通にするまで

小学校の教室横に、1週間の予定を書く黒板がある。月曜に紙を係の児童へ渡すのが地味に面倒で、よく忘れる。 私だけの、私が便利になるツールとして作った。

よく忘れる、月曜の紙。毎週、係の児童に渡して黒板へ書いてもらう。

以前 · 手作業
  • 年間予定を目で追う
  • 子ども向けだけ紙にまとめる
  • 月曜に係へ渡す。よく忘れる
いま · 自動化
  • 年間Excelを取り込む
  • 日曜20時に今週分が更新される
  • 学校メールが届き、印刷して渡す

決めごと

掲示板はログイン必須 直結しない。原本を手元に置く。

CSVは月ごと 年間Excelを正とする。行事予定列だけ。日直名は出さない。

朝6時出勤 日曜20:00に、同じURLを更新する。

学校メールへ 最初は迷惑メール。解除して、届くようにした。

動かす

TRIGGER

トリガー

毎週日曜 20:00。GitHub Actions。朝6時出勤の前に、表ができている。

SOURCE

ソース

学校の年間予定Excel。閲覧のみ原本から、行事予定の列だけ使う。

PROCESS

処理

翌月曜〜日曜を抜き出し、印刷用のHTMLにする。

DELIVER

届ける先

GitHub Pages の同じURLを更新し、学校メールへ今週分のリンクを送る。

到着。月曜に印刷して、子どもへ渡す表。

公開ページの例（2学期始めの週）。月曜に印刷して子どもへ渡し、黒板へ書いてもらう。

掲示板直結も、原本を毎回自動で取りに行くことも、やらなかった。 できるところだけ自動化して、紙を渡す瞬間だけ人手に残した。 完璧な連携より、月曜に忘れないこと。 公開ページ: awayuki-ai.github.io/weekly-blackboard-schedule
