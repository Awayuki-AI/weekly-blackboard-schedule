教室の黒板予定を、
日曜のメール1通にするまで

小学校の教室横に、1週間の予定を書く黒板がある。月曜に紙を係の児童へ渡すのが地味に面倒で、よく忘れる。 私だけの、私が便利になるツールとして作った。

01 このやりとりで決めたこと
分岐 1

掲示板直結はできない

校務の掲示板はログイン必須だった。自動取得は権限の壁で折れるので、学校の原本をダウンロードする運用にした。

分岐 2

CSVではなく年間Excel

CSVは月ごと。Excelなら年間まとめて取れる。行事予定の列だけ使い、日直名は公開しない。

分岐 3

日曜20時に同じURLを更新

朝6時出勤なので、月曜朝には表ができている必要がある。届ける先は印刷ページ。あとからメールも足した。

分岐 4

学校メールへ届ける

最初は個人メール。2学期から学校メールへ。一度は弾かれたが、学校アドレスで送り直し、迷惑メールから受信箱へ移した。

02 何が変わったか

以前（手作業）

  • 年間予定を目で追う
  • 子ども向けだけ紙にまとめる
  • 月曜に係へ渡す。よく忘れる

いま（自動化）

  • 年間Excelを取り込む
  • 日曜20時に今週分が更新される
  • 学校メールが届き、印刷して渡す
03 自動化ツールの4パーツ
TRIGGER

トリガー

毎週日曜 20:00
GitHub Actions。朝6時出勤前に表ができている。

SOURCE

ソース元

学校の年間予定Excel
閲覧のみ原本はダウンロード。行事予定列だけ使う。

PROCESS

処理

翌月曜〜日曜を抽出
全月シートから該当週だけ抜き、印刷用HTMLにする。

DELIVER

届ける先

Pages ＋ メール
同じURLを更新し、学校メールへ今週分のリンクを送る。

04 データの流れ
学校Excel（年間） → 行事予定だけ抽出 → school-events.json → 印刷用HTML → GitHub Pages → Resend → 学校メール
05 完成した報告ツールの画面

公開ページの例（2学期始めの週）。月曜に印刷して子どもへ渡し、黒板へ書いてもらう。

06 いまも毎週使っている

完璧な連携より、月曜に忘れないこと

掲示板直結も、学校の原本を毎回自動で取りに行くことも、やらなかった。 できるところだけ自動化して、紙を渡す瞬間だけ人手に残した。 日曜のメールが届けば、月曜朝に思い出さなくてよい。
