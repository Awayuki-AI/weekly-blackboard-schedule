ADS 2ヶ月目課題

面倒な報告を自動化する
黒板予定ツールの4パーツ

毎週、年間予定から子ども向けだけを抜き出し、月曜に渡す表を作っていた作業を、 日曜夜に自動更新される印刷用ページへ置き換える。

01 TRIGGER

トリガー

毎週日曜 20:00
GitHub Actions が起動。朝6時出勤前に表ができている。

02 SOURCE

ソース元

学校の年間予定CSV
閲覧のみシートをダウンロードして配置。更新時は差し替え。

03 PROCESS

処理

翌月曜〜日曜を抽出
教員・保護者向けなどを除外し、印刷しやすいHTMLにする。

04 DELIVER

届ける先

同じURLの印刷ページ
開いて印刷し、子どもに渡して黒板へ書いてもらう。

消えた面倒

以前: 掲示板の年間予定を目で追い → 子どもに関係する行をピックアップ → 表を作る → 月曜に渡す。
いま: 学校の年間予定CSVを置いておけば、日曜夜にページが更新される。月曜朝は印刷するだけ。 （学校側の原本が変わったら、CSVをダウンロードし直して差し替える）
